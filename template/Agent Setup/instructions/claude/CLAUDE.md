# Global instructions for Claude

- **Agents Workspace (shared multi-agent projects)**: `{{WORKSPACE}}` is the shared parent folder for work across several agents. Read `{{WORKSPACE}}/AGENTS.md` before working anywhere inside it. Short version: your agent name is `Claude`. Start work on a project with `{{WORKSPACE}}/_scripts/new-version.sh <project> Claude`, edit only the `Claude/<version>/` folder it prints, never `main/` or another agent's folder, and publish with `{{WORKSPACE}}/_scripts/publish-version.sh <project> Claude <version>`. Never hand-edit `main/` or `LAST-EDITED-BY.md`. If a project under `Projects/` is flat (no `main/` or `<Agent>/<version>/` folders), retrofit it first as AGENTS.md describes, including empty `v1/` placeholders for every other agent. Build, install and deploy anything persistent from `main/`, never from your working copy.
- **Folder names**: version folders are `v1`, `v2`, `v3`. Name project and task folders for what they hold. Never create folders named after a date, a timestamp or a chat title, and never create `work/` + `outputs/` session folders.
- **Everything stays in the workspace**: save every file you create (scratch renders, screenshots, downloads, generated images) in your `Claude/<version>/` folder for a project, or in `{{WORKSPACE}}/Tasks/Claude/<task-name>/` for one-off work. Never save to a temp folder, a scratchpad outside the workspace or a home config folder.
- **Shared skills and setup**: custom skills live in `{{WORKSPACE}}/Agent Setup/skills/` and are linked into `~/.claude/skills/`. Create new skills there. Edit instructions and memory in `{{WORKSPACE}}/Agent Setup/`, never through a home config link, and never replace a link with a real file.
- **Moving folders**: never move or rename a workspace folder directly. Other agents' chat history is bound to folder paths and breaks silently. Follow the "Moving or renaming a folder" section of AGENTS.md.
